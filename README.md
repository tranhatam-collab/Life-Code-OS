## 4. Tuyên ngôn bắt buộc

Life Code phải tuân thủ 8 nguyên tắc:

1. **Không tuyệt đối hóa số phận**  
   Mọi kết luận đều là xác suất, không phải định mệnh cố định.

2. **Không kết luận từ một lớp đơn lẻ**  
   Mọi nhận định mạnh phải có cross-layer agreement.

3. **Mọi output phải có confidence**  
   Không có confidence thì không được dùng kết luận mạnh.

4. **Mọi forecast phải có điều kiện đúng và điều kiện sai**  
   Không được viết như lời tiên tri.

5. **Mọi output phải dẫn tới hành động**  
   Nếu chỉ mô tả mà không chuyển thành hành động, hệ chưa hoàn chỉnh.

6. **Mọi layer thiếu dữ liệu phải được đánh dấu rõ**  
   Không tự bịa score.

7. **AI chỉ là tầng tăng cường, không phá triết lý gốc**  
   Rule-based architecture là nền trước.

8. **Con người luôn có khả năng đổi quỹ đạo**  
   Life Code đọc trajectory, không đọc fixed fate.

## 19. Bước 1 đã khóa: Life Code Index

### Mục tiêu

Bước 1 chỉ làm một việc:
**Tạo bộ máy tính Life Code Index chuẩn v1**

### 12 layer chuẩn

1. Chrono Code
2. Name Code
3. Birth Matrix
4. Face Code
5. Hand Code
6. Foot Code
7. Behavior Code
8. Social Fate Code
9. Relationship Code
10. Wealth Code
11. Health Risk Code
12. Mission Code

### Trọng số chuẩn v1

* Chrono Code: 0.15
* Name Code: 0.08
* Birth Matrix: 0.15
* Face Code: 0.08
* Hand Code: 0.10
* Foot Code: 0.05
* Behavior Code: 0.12
* Social Fate Code: 0.07
* Relationship Code: 0.05
* Wealth Code: 0.05
* Health Risk Code: 0.05
* Mission Code: 0.05

### Công thức

**Raw LCI**

```text
LCI = Σ(LayerScore × LayerWeight)
```

**Adjusted LCI**

```text
AdjustedLCI = Σ(LayerScore × LayerWeight × LayerConfidence)
```

**Data Coverage**

```text
DataCoverage = Σ(ValidLayerWeights)
```

**Normalized LCI**

```text
NormalizedLCI = Σ(LayerScore × LayerWeight) / Σ(ValidLayerWeights)
```

### Status chuẩn

* `insufficient`
* `partial`
* `strong`
* `full`

### Rule coverage

* coverage < 0.25 → insufficient
* 0.25 đến < 0.55 → partial
* 0.55 đến < 0.80 → strong
* ≥ 0.80 → full

### Rule thiếu dữ liệu

Khi không có dữ liệu cho một layer:

* score = null
* confidence = 0
* status = "missing"

Không được tự bịa score.
