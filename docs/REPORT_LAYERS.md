# Bốn lớp bắt buộc trong mọi report (README §11)

**Nguồn:** `README.md` mục **11**. Mọi report **Level 1 → Level 9** đều phải có đủ 4 lớp sau (có thể rút gọn theo level nhưng không được bỏ khái niệm).

---

## 1. Identity Layer

**Câu hỏi:** Người này là ai ở tầng cấu trúc?

---

## 2. Analysis Layer

**Nội dung:** Pattern, field, signal, score.

---

## 3. Timeline Layer

**Nội dung:** Đang ở chu kỳ nào, sắp vào vùng nào.

---

## 4. Action Layer

**Nội dung:** Cần **dừng gì**, **làm gì**, **xây gì**, **bảo vệ gì** — khớp cấu trúc `recommendations` trong README §17 (`stop` / `start` / `build` / `protect`).

---
